# Arcade Attic

Kids clubhouse MVP: build an attic, place arcade machine shells, author/remix tiny minigames, and party with simulated friends. Creation first, party play second — no open stranger chat.

## Run

```bash
npm install
npm run dev
```

## Play loop

1. Name your attic (or continue a save / visit `ATTIC-DEMO`)
2. Place décor on the loft grid
3. Author an **Orb Catch** or **Wall Zap** cabinet (or remix a friend’s)
4. Tap a cabinet to play
5. Open a party, simulate friends joining, let them play

Progress saves to `localStorage`.
